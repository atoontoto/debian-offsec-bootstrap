# Security policy

Report bootstrap vulnerabilities privately through the repository security advisory
feature. Do not include assessment data, credentials, tokens, BloodHound `.env`
files, or customer information. Supported releases are the current stable branch.

The project does not weaken AppArmor, Secure Boot, firewall rules, sudoers, DNS,
NetworkManager, or system-wide Python. A vulnerability in a third-party tool should
be reported to that tool's upstream maintainer.
